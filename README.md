
# Weather Data Analysis and Prediction

## Project Overview

This project analyzes historical weather data
and predicts future temperature trends using
Machine Learning.

## Objective

To study historical temperature patterns and
predict future temperature trends using
Linear Regression.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit

## Algorithm

Linear Regression

## Project Features

1. Historical weather data analysis
2. Data cleaning
3. Temperature visualization
4. Average, maximum and minimum temperature
5. Machine Learning prediction
6. Model evaluation
7. Future temperature prediction

## Project Structure

Weather_Data_Analysis/
- app.py
- model.py
- requirements.txt
- README.md
- data/weather.csv

## Installation

Install the required libraries:

pip install -r requirements.txt

## Run Project

streamlit run app.py

## Conclusion

This project demonstrates basic data analysis,
visualization and Machine Learning techniques
for temperature trend prediction.

## Limitation

The included dataset is illustrative.
The model predicts a simple temperature trend
and is not a professional weather forecast.
